📋 Instrucciones para crear los iconos:

  1. Haz screenshot de cada icono individual (usa la herramienta de captura de tu sistema)
  2. Recorta cada screenshot para que solo contenga el icono
  3. Redimensiona cada imagen al tamaño correspondiente usando herramientas online
  4. Guarda cada icono como PNG en la carpeta public/icons/
  5. Renombra según el formato: icon-72x72.png, icon-96x96.png, etc.
